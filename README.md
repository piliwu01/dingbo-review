## 複習手遊玩法

- 共 4 關、40 題：夜行逢鬼 → 鬥智渡水 → 智縛鬼 → 宛市決戰
- 答對攻擊魔王（3 連擊以上有加成），答錯扣 12 點血量
- 每題附解析，破關後有錯題複習表
- 最高分與破關進度保存在瀏覽器
